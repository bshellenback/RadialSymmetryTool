Radial Symmetry Tool for Maya

This radial symmetry tool packages many steps that 3D modelers have to 
undertake in order to create radial symmetry in Maya. Artists must move 
the pivot of their object manually, calculate how much an object should
be rotated based on how many copies of the object they want, use 
"duplicate special" to duplicate the object around the axis, combine the
 geometry or painstakingly select the vertices they want to merge, and 
 try different merge thresholds until they get it just right. If a 
 mistake is made in this process, then artists need to delete their 
 work and redo almost everything. My tool solves this issue through 
 making these steps quicker, and by making the geometry much easier to 
 edit after it is created! 

With this tool, artists can model anything that needs some kind of 
radial symmetry. The tool provides buttons to instantly move the pivot 
point. The user can also add different axes of rotation, and edit how 
many instances of the geometry are copied on each axis. The geometry is 
instanced, so the user can edit any of the pieces and automatically 
update the rest of the mesh. Additionally, the user can add a name to 
the geometry and either combine the meshes or merge the verticies 
together, with the merge threshold being controllable. Most importantly,
nothing is permanent on the tool until the window is closed, which means
that users can go back and change any parameter and instantly see new
results in real-time, making the tool extremely convienient and 
time-saving.
